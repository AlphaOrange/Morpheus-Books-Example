# Electric City (Example Book)

A book for the interactive story engine _Morpheus_.

This interactive book brings you to Electric City, a small hub in the dystopian Electric Plains. _Electric City_ embraces a cyberpunk style and presents a range of eerie characters in a futuristic small town environment. However, this is mainly an example case for _Morpheus_ that implements the latest features and is primarily used for testing. Don't expect bigger updates in content or sophisticated story-telling.  
First two version numbers are tied to _Morpheus_ version numbers.
